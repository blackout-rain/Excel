## 約束
- Excel で保存されたファイルは「機種販売入力」にプルダウン(拡張データ入力規則)があり、openpyxl で保存すると消える。値の差し替えは XML を直接書き換える(`tools/ladder/patch.py`)。
- 書き換えたら `fullCalcOnLoad` を付け、Excel で開いたときに再計算させる。

## ラダー更新の手順(`tools/ladder/`)
1. `python3 -I build_target.py <店舗一覧.xlsx>` → `target.json`
2. `python3 -I patch.py <進捗確認.xlsx> target.json <出力.xlsx>`(変わったセルを一覧表示)
3. (必要なら)LibreOffice で再計算したコピーを作り、`patch3.py` で「進捗確認」シートの保存済み計算結果を更新
4. `RECALC=<xlsxスキルの recalc.py> python3 -I test_ladder.py <出力.xlsx> target.json` で境界値テスト(32件)
